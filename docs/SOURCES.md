# Source provenance

The bundled catalogue is a small starter selection, not a complete map of onion services. Onion addresses change; entries must be checked again before relying on them. The check date refers to this repository's review of the operator-published source, not a live availability test.

## Official Tor Project sources

- Onion services index: https://onion.torproject.org/
- Onion Services Ecosystem: https://onionservices.torproject.org/
- What onion services are: https://support.torproject.org/about-tor/onion-services/what-is-a-dot-onion/
- Onion-service troubleshooting: https://support.torproject.org/tor-browser/encountering-issues/troubleshooting-onion-services/
- Tor Browser downloads: https://www.torproject.org/download/

The Tor Project's published index includes the seeded blog, community, forum, GitLab and metrics addresses. Umbrella records them as operator-listed, not independently certified as safe or live.

## Journalism and public-interest sources

- SecureDrop directory: https://securedrop.org/directory/
- SecureDrop stable documentation: https://docs.securedrop.org/en/stable/
- SecureDrop source guidance: https://docs.securedrop.org/en/stable/source/before_you_submit.html
- Freedom of the Press Foundation: https://freedom.press/
- OnionShare: https://onionshare.org/
- Tails: https://tails.net/
- EFF Surveillance Self-Defense: https://ssd.eff.org/
- Access Now Digital Security Helpline: https://www.accessnow.org/help/

The SecureDrop documentation itself publishes its documentation onion address. The directory advises researchers to compare submission details with the specific newsroom's own official instructions. Umbrella repeats that caution.

## Safe update policy

1. Discover addresses from the operator's own HTTPS site or official documentation.
2. Never treat an unverified aggregator, screenshot or search result as authoritative provenance.
3. Check v3 hostname syntax and reject credential-bearing URLs, non-HTTPS ordinary sites and unsupported host types.
4. Record the evidence URL and review date.
5. Do not crawl onion destinations or run a live URL checker through a third party as part of client-side browsing.
6. Treat listing, availability, operator identity and content safety as separate questions.
