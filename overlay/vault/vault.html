Umbra Vault

Encrypted backup of your bookmarks and saved logins, in one file on this device. Nothing is uploaded.

Export

Saved logins are off. Like Tor Browser, Umbra doesn't store passwords by default (no certificate or key database on disk), so there are none to export.

Import

Bookmarks go into a new folder under Other Bookmarks. Logins you already have are skipped.

How it's protected

  • AES-256-GCM encryption with a key derived using PBKDF2-HMAC-SHA-256 (600,000 iterations, random salt), all from the browser's built-in, audited NSS crypto. Umbra doesn't use any custom cryptography.
  • The file format and settings are authenticated, so any change to the file is detected.
  • If you forget the passphrase, the file can't be recovered. Nobody, including Umbra, can reset it.
  • Saved logins are only as safe as the passphrase. A long, random passphrase matters most.
